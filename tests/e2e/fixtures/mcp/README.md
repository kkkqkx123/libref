# MCP 工具返回内容核查样本

本目录说明 `tests/e2e/render_mcp_outputs.py` 的人工核查输入与判读方式。默认全部离线：文档、源码、注册表缓存、依赖、待审与任务都由脚本在临时库中确定性生成；只有显式加 `--network` 才执行真实站点探查与真实仓库探查。

## 运行

```bash
uv run python tests/e2e/render_mcp_outputs.py
uv run python tests/e2e/render_mcp_outputs.py --network
```

输出到 `tests/e2e/outputs/mcp/`，一个工具一份文本，附 `SUMMARY.txt`。结构化载荷原样落盘，`_is_error` 是协议层错误标记，其余字段为工具返回内容。

## 核查点

- 检索问答：`search` 看三种预设的条目字段、降级原因、可答性与空查询错误；`answer` 看缺模型时的不可用原因。
- 阅读目录：`read_doc` 的整页、窗口、整节三模式要带块序号与定位字段，正文只出现一次；`catalog` 区分库列表与版本列表。
- 发现解析：`library_search`、`web_search`、`github_search` 的候选取自预置缓存，核对生态、名称、版本、地址、来源与排序；`resolve` 核对文档地址与空名称错误。
- 探查：离线用例只验证参数错误；联网用例核对预算标记、跟随提示、目录树、采样与限定回显。
- 源码洞察：四类洞察逐视图核对频次排序、同现条件、参数形状、序列证据的跳过标记、特征树前缀、分组、健康、标签、符号定位、调用过滤与导入扇入扇出。
- 治理运维：`review` 看待审排序与流转结果；`job_show` 看列表与详情；`submit_feedback` 看返回编号且审核状态未改变。
- 索引申请：核对申请编号、下一步工具、状态与等待的超时标记、审批队列与驳回原因；缺 scope 的情况由集成测试覆盖。

`SUMMARY.txt` 列出执行用例数、跳过的联网用例与非预期的错误信封。联网失败不算回归，只表示环境不可用。
