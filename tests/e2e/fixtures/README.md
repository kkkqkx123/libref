# e2e fixtures 说明

来源与许可证随 manifest 记录，更新提交需同步说明。

放置原则只放最小样本，不整体搬运第三方仓库。
完整仓库验证走网络，由端到端 runner 在运行时拉取，
常规单元测试只读本地样本与受控采样，不出网。

## 布局

- manifest.json：三语言目标与固定标签，网络项缺省跳过
- doc_manifest.json：文档站点目标与固定地址版本，网络项缺省跳过

三语言最小样本已上移至顶层 tests/fixtures/parsing/ 目录，供单元层离线精确断言，
本目录不再保留副本。

Python 完整采样直接读本地参考目录，不复制整仓。
受控采样限制文件数与总耗时，断言与标准库解析一致。

网络仓经同步脚本拉取到 tests/e2e/repos/ 目录持久复用，
本地路径沿用仓库管理入口的持久布局，更新标签时同步更新，
审查报告落到 tests/e2e/outputs/{lang}/ 目录，两目录均不入库。
