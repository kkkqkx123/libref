# 源码索引与挖掘链路（现状实现）

> 描述对象是当前代码已落地的源码链。
> 挖掘算法包保持纯内存，落库一律由编排层完成。

## 1. 入口与仓库获取

统一编排在 `services/code` 包内，复用文档链的版本目录。
显式地址、按名解析、无地址时按登记与缓存逐级回退三种来源，同一版本登记不同来源直接拒绝。
先保证库版本行存在，再做后续落库，保证源码与文档共享同一版本标识。
索引与挖掘分为两种任务类型，分别由各自的任务消费函数处理，互不耦合。
命令行同步与异步路径均按有无密钥装配向量组件，有则收尾同步，无则只写真源。

仓库管理以固定根目录为基础，远端浅克隆或拉取更新并记录提交标识，本地目录直接使用。
文件遍历按语言后缀过滤。

## 2. 抽取与解析

语言配置声明语言名、语法包、文件后缀与配置版本，新增语言只加查询模块并登记。
指纹联合运行时、语法包版本、查询文本与配置版本，任一变化缓存全量失效。

通用引擎按指纹缓存解析器与查询，首遍收声明与别名，次遍收调用，注释跨度用于判定文档说明。
声明装配限定名、种类、所属文件、起止行、父级、深度、签名、参数名、参数类型、返回类型、基类、字节范围与文档有无。
调用记录原始文本、实参摘要、接收者与函数拆分、外围调用者、行与字节范围。
两遍解析按文件汇总声明与导入映射，变量别名按调用者作用域叠加出生效映射，按文件、外围调用者、起始字节排序逐个解析，结论为显式抽取、推导、待定三档，并附带解析来源。来源区分同文件命中、别名直接展开、外部调用显性、别名后缀消歧、工厂返回改写、自身引用、通用继承上查、接收者类型回填、后缀全局消歧、作用域链消歧、导入加权、标准库与内建排除、形参遮蔽与未解析。

逐文件增量键为主键加文件内容哈希，命中复用并计数，否则解析后写回，收尾按存活集合清扫过期缓存。原始调用的解析在每批摄取时按当前全量声明重算，缓存复用不影响来源结论。

## 3. 落库与源码分块

实体与调用均用语义键哈希保证幂等，写入后清扫版本内过期行。实体键为版本加限定名加种类，调用键为仓库加文件加调用者加字节区间加被调名加实参形状，格式化抖动收敛到字节变化。
实体落库包含父、签名、参数名、参数类型、基类、返回类型、字节区间、深度、文件、行范围与文档标记。调用落库包含被调引用、被调名、实参、接收者、函数名、实参数、序号、字节区间、作用域键、置信度、解析来源与调用者引用。调用者引用按限定名加种类回填，找不到置空。
待定调用在审核表记待审，删除调用时同步清理对应行。
导入边单独成表，记录导入文件、本地别名、解析后目标与边种类，数据来自解析已用的别名表，随版本全量刷新。查询侧提供按目标查导入者与按文件查导出两类读接口，挖掘主路暂不依赖它。
源码分块按文件分组装配，成员原文直接作块文本，两路预算各切一遍，向量路配口语头，过小块向同组相邻块合并，有独立文档说明的成员不参与合并。
块转文档形态时回填限定名名单，合并来源一并计入，落库时经文档表复用，全文索引同样可查源码块，元数据中的实体名单供检索侧精确匹配。

源码落库后同样走收尾向量同步，与文档链共用同一共享函数，收集的删增标识来自各文件的存储返回。
向量缺失时只写真源，后续可经整版重灌补齐。

## 4. 挖掘与审核

按版本读出调用实例，按作用域分组保序成序列，过滤超长与过短，可选按频次显式剪枝。
归一化后做闭合模式挖掘，结果反归一化后幂等写入并清扫过期模式。序列输入保持纯被调名，来源与实参不进排序，只用于调试与健康统计。
特征树优先按符号表的父与种类挂载，缺失时回退到按点分推导，保证包与类层级不混淆，调用数沿父链累加，作用域数按键去重。
分组按作用域构造集合，做确定性层次合并。
三表在调用为空或序列为空时保持一致清空。

挖掘与读取均尊重审核结论：冲突始终排除，待定默认排除、显式要求时纳入，已核准的待定视为可用。
读模型提供频次、参数形态、同作用域相关接口、模式列表与证据、特征树前缀浏览、分组浏览、导入边双向查询、签名查询与来源分布健康计数。
模式证据按有序子序列在调用序列中匹配，查询时计算，不持久化。证据在实参与共现之外联查被调与调用者的签名、参数名与返回类型，渲染与片段中携带签名，返回形状不变。归纳提示在参数形态与共现之外联查签名，按接口拼装短签名段落，不引入原文源码。
审核提供待定列表、批准、标冲突、重开，只接受合法流转。审核语义只看置信度与复核状态，来源列仅用于排错与统计。

## 5. 检索消费

源码块与文档块共用文档表，全文单路天然可查源码块。
混合检索按版本读出模式与分组，块有实体名单时做精确交集匹配，无名单时回退名称启发式。
命中支持度按版本内最大值归一，分组命中要求同组两个以上成员，加权只作用于融合后的头部，为零时退化为纯融合排序。来源列与实参与排序无关。
问答在检索命中后按标识回查全文，材料在行边界处截断，引用保留检索顺序。
