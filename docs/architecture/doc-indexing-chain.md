# 文档采集与检索链路（现状实现）

> 描述对象是当前代码已落地的文档链。
> 约定：`真源`指 SQLite 内 `pages/documents` 与 FTS；`派生`指 Qdrant 向量点。
> 所有路径均为 `src/libref/` 下相对路径。

## 1. 入口与编排位置

统一编排在 `services/ingest.py: IngestService`，三个出口只做参数解析与调用：

- `cli.py` 经同步直调或经 `jobs` 异步驱动。
- `mcp_server/server.py` 文档工具经 `services/search.py, pages.py`。
- `web/app.py` 检索与抓取路由经 `services/*`。
- 装配收口在 `services/factory.py`，按有无密钥决定返回向量存储与编码函数还是空，空即纯全文路。

任务化在 `services/jobs.py: JobManager`：内存队列提交，同步回写 `jobs` 表，worker 执行后回写，`heartbeat` 按页续写，`recover` 处理 `stale`。
治理表经版本化迁移建表，运行时按需幂等确保。
同版本串行由数据库版本锁保证，跨进程可见，超时心跳可接管，退出时只释放自有锁。

目录与版本归属唯一写入点在 `services/libraries.py`。
按名称抓取先走 `services/resolver.py`，查注册表、写缓存、应用覆盖规则后再进入标准抓取。

## 2. 发现与抓取

`crawler/url_seeder.py: UrlSeeder.discover` 为唯一发现入口：
robots 声明的 sitemap 候选、目录逐级回退找 `llms.txt`、站点根与起始目录逐级试 `sitemap` 变体，支持压缩与索引递归。
同站过滤、robots 过滤、按文档身份去重（`crawler/scope.py: crawl_key` 折叠片段与"只带锚点/跟踪
参数"的查询，所以锚点清单里同一页的多个条目只算一份）后经同一处的纯决策过滤，再做起始页回退与
分页截断。

`crawler/fetcher.py` 经注入客户端执行条件抓取，支持增量头、按 host 节流、指数退避。
`ingest._scrape_async` 按并发信号量抓取，单页失败只记该页，不中断整批。
可选快照存原始字节，超配额只计数跳过。
渲染候选在未开启浏览器降级时记为跳过，收尾按跳过数告警，提示是否需要重扫。

## 3. 净化与分块

`text/normalize.py` 按后缀优先、MIME 其次分派四类，HTML 经 `crawler/extract.py` 净化转 Markdown，Markdown 与纯文本只做空行收敛，源码包裹为围栏块。
净化结果按种类加预算指纹加原文哈希缓存。

`chunking/splitter.py` 一次切分产出向量与全文两股块流：
标题路径切节、过小同级节贪心合并、超限按行装配并保护围栏、超长单行按句子边界拆分。
两路采用不同计量口径，全文路先做链接降噪与中文展开，与向量路重复的内容直接丢弃，两路共享来源分组。
块携带实体名单字段，文档块为空，源码块由抽取侧回填。
过滤后重建序号与前后链，只向前记录重叠来源，按源文回填字符区间。

## 4. 落库与向量同步

`store/document_store.py: store_page` 是唯一写入口，单事务提交，结局覆盖存入、不变、缺席、空页、跳过、失败。
存入时按内容哈希复用旧行，删除无复用旧行，返回删增与复用三组标识。
全文索引由触发器自动同步。
缺席清扫只在发现源有效且未截断时执行，并写删除留痕。

向量同步收口在 `services/maintenance.py` 的共享函数，文档与源码两链共用：
集合治理、删旧点、回查新增块、跳过全文专用块、组装编码文本、超限截尾计数、批量编码写入。
失败只计数告警，不推翻真源。
整版重灌与整版删除分别负责全量回灌与真源向量快照仓库的同步清理。

## 5. 检索语义

默认检索语义为混合检索：双路召回、按排名融合、同源去重、可选重排、挖掘加权、窗口扩展，失败标记降级。
每次检索附带证据充分度判定：候选池与头部对查询词项的覆盖率合成一个 0～1 的值，映射为可答、弱、不可答三档；
查询与语料不共享书写系统时覆盖率不可测量，判定停在"弱"而不是"不可答"。判定只出现在状态里，不过滤结果；
问答链路在"不可答"时直接返回空答案并标注原因，不付生成调用。
精确全文查保留为显式入口，只走 FTS 单路。
命令行默认走混合，加精确开关回退单路；网页默认混合；MCP 默认工具走混合，另设精确工具对应单路。
预设只在服务层解释：精确路由到全文单路，其余走融合召回；窗口扩展开关的优先级为调用方显式指定、预设、配置依次降低。
问答在混合检索之上回查全文组装材料生成，引用保留检索顺序。材料预算为硬上限：超出部分整条丢弃并以省略标记告知模型，
引用编号与保留材料一一对应；问答不展开窗口，窗口扩展只为检索结果的展示服务。
