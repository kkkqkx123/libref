# 模型使用规范

## 1. 允许与禁止

嵌入只允许免费的 `bge-m3`，维度1024。重排只允许同系列配对重排模型，与嵌入同属免费档。问答固定免费的 Qwen/Qwen3.5-4B，默认仍须显式开启；不启用任何付费或第三方模型。

禁止引入其他嵌入模型、其他重排模型、其他厂商专用模型。禁止为换模型新增传输依赖。禁止把模型权重随仓库分发。

## 2. 参考文件

实现以应用配置模块为唯一配置来源，以仓库根环境文件为唯一密钥来源，以模板环境文件为唯一提交形态。请求形态以手工验证目录下三份验证文件为准，分别对应嵌入、重排与本地同协议端点。编码文本构造以向量存储模块的组装函数为准，写入与查询共用同一构造。模型与维度登记以向量存储的集合治理与库内元数据表为准。编排接线以抓取编排的向量同步与检索服务的融合检索为准。

## 3. 密钥加载

密钥经带前缀的环境变量注入，不入库。应用配置从仓库根环境文件自动读取，环境变量优先于文件。模板环境文件入库，真实环境文件不进版本库。

默认仓库根环境文件存在，直接读取使用。不存在时不报错，传输层视为无密钥，跳过全部实际调用，走纯全文降级路径。手工验证文件执行时密钥经命令行变量传入，不写入文件。

## 4. 调用形态

三路共用同一基址与同一密钥。嵌入按模型名加文本列表批量调用，返回与输入顺序对应的向量并做归一。重排按模型名加查询加文档列表调用，返回按相关度排序的分数与文档。问答按模型名加消息列表调用，首版只做非流式，思考默认关闭。

批量大小、超时、重试次数与退避策略由传输模块内聚管理，编排层不重复实现。限流与服务端错误退避重试，其余失败直接抛错。维度与数量失配直接抛错，不静默截断。

## 5. 禁用与降级

密钥缺失、模型名为空或开关关闭时对应链路禁用。嵌入禁用则抓取不同步向量，检索只走全文。重排禁用则融合后直接进入频次加成。问答禁用则不提供生成入口。

禁用不是错误，不抛错、不阻塞真源写入，失败点数计入独立计数供运维发现。服务端不可达对应测试跳过，服务运行时对应请求降级并标记，不在传输内静默。

## 6. 文本与治理

编码文本为标题路径在前、正文在后，写入与查询一致。模型名与维度登记在库内元数据表，任一变更触发集合删除重建，重灌按真源全量执行。

## 7. 合规

密钥不进库、不进日志、不进模板。环境文件变更不触发向量失效，只有模型名或维度变更才触发。新增语言、新增生态不影响本规范。
