# 跨档案特征漂移对比设计

本文描述同库跨版本或同版本跨档案的特征漂移对比能力。对比只做读时计算，不新增存储表。

## 对比对象

- 同库不同版本：升级前后同一档案名的派生表并列加载，输出接口增删与形态变化。
- 同版本不同档案：官方示例档案与参考项目档案并列加载，输出场景差异。

对比限定在这两种范围内，不做跨库对比。

## 漂移清单

读模型并行加载两档案的序列模式与形态派生表，做集合差与分布对比，产出三类条目：新增、消失、支持度显著变化。条目按变化绝对值倒序，截断数由漂移清单配置项控制，默认二十。

同一档案自比对无漂移，这是回归门禁之一。版本升级的接口增删须能被清单反映，这是验收标准之一。

## 增量语义

指纹变化只重算受影响部分，形制与增量索引一致。对比本身不写库，重复调用结果一致。

## 消费

读模型提供档案对比方法，洞察视图提供漂移视图，网页侧提供与现有视图同形制的对比页。漂移条目只作展示，不参与检索排序。
