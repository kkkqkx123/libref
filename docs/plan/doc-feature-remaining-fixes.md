# 文档特征剩余问题清单与修复方案

依据：`docs/tests/doc-feature-unblocked-analysis.md`、`docs/plan/doc-feature-edge-and-evaluation-fixes.md`、冻结归档评测报告与当前派生数据。本文只记录剩余问题、处理边界与本轮改动，不调整权重门禁。

## 一、问题清单

### 数据问题

1. **漂移仍未绑定到对象**。块级 `deprecated` 直接产生 `drift`，误报集中在生命周期枚举、安全基线、否定式问答和泛化 changelog；现有 40 条样本中误报 7 条。
2. **一条节点标签没有目标块证据**。`VU22` 期望 `packages.runtime-core.src.devtools` 父链，但目标 URL 下没有对应 `doc_feature_node_links`。
3. **弱边仍大量存在**。`context_symbol` 与 `name_fuzzy` 合计远多于强边；它们可用于诊断，但不能作为对齐真值或过滤依据。
4. **有效样本稀薄**。fiber 22、Rocket 36、jsoup 11 条有效样本，低覆盖来自样本短和别名缺失，不是统一 `minsup` 的结果。
5. **生产实体来源绑定仍未接线**。生产链路没有显式写入 `entity_source_bindings`，无绑定时会回落文档版本自身。
6. **真实嵌入与独立语义复核缺失**。离线词袋替身只能解释排序机制，不能证明生产收益；同源一致性不能替代语义真值。

### 指标问题

1. 强边与弱边已分列，但检索加权仍把 `name_fuzzy` 累计成正贡献。
2. 排名归因已有站点汇总，逐查询明细没有落盘到报告。
3. 排序差分仍有正有负，不能据此冻结增益门禁。

### 处理逻辑问题

1. 漂移判定没有检查弃用词所在句子的对象与否定语义。
2. 弱边累计加成会把“名称碰巧重叠”放大为排名信号。
3. 节点标签规范缺少“必须来自目标块关联”的显式约束。

## 二、本轮修改方案

### 漂移对象化

`compare_consistency` 接收实体名映射，按句子检查弃用词：只有弃用词所在句子同时点名该块的实体候选，且不是否定式或外部标准语境时才写 `drift`；否则写 `unknown`。对象绑定使用全部对齐候选，标题、安全基线、生命周期枚举和 changelog 由上下文规则排除。强边仍只用于实体回写、节点关联和模式判定。不新增判定枚举，不写门禁阈值。

### 节点标签清理

删除 `VU22` 中没有目标块证据的 `expected_feature_nodes`。其余节点标签仍只在父链完整的文档块上保留。

### 弱边退出加权

`ALIGNMENT_BONUS` 只保留 `symbol` 与 `signature`。`context_symbol` 与 `name_fuzzy` 仍写入洞察视图，但不再产生排序加成，也不会进入实体回写、节点关联与一致性证据。

### 归因落盘

评测报告在站点汇总后输出每条非 `unchanged` 的排名明细，包含题号、归因类别与 off/on 名次，便于逐题复核而不是只看聚合区间。

## 三、验证口径

- 纯算法单测覆盖绑定漂移、无对象弃用、否定式弃用。
- 集成测试保留模型归纳成功与失败用例，并用绑定实体名构造弃用句。
- 判定集结构测试确认其余节点标签非空；`VU22` 不再带无证据节点。冻结归档中的其余 drift 题需要人工复核题面是否仍与对象化判定一致，不在本轮自动改标签。
- 过滤与加权单测确认弱边不再产生加成。

## 四、本轮不修改的内容

- 不把 `not_target`、`partial`、`ambiguous` 片段提升为目标调用。
- 不全局下调 `minsup`，不补造缺失父链。
- 不按生态或版本猜测生产实体来源；接线需显式配置。
- 不调用真实模型端点，不以离线替身结论设置门禁。
- 不改变 `doc_feature_alpha=0` 的默认行为。
