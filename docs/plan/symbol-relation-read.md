# 符号调用导入边读取链路补齐

> 依据：当前符号表、调用表、导入边表已落库，解析来源与调用者引用已回填，证据与归纳已联查短签名，读模型部分方法已实现但三端出口均未透出。
> 目标：已落库的每个字段都有对应读法，调用图可双向走，导入边可查扇入扇出，签名装配全链路一致，身份与缓存失效可解释。
> 范围：只改原模块，读模型、挖掘输入装配、标识与缓存、三个薄出口的参数透传与结果透出、相关文档与测试。不改抓取分支与向量主路。
> 约束：只改原模块，不建替代模块；新增读视图落在原读模型内，新增文件仅按职责拆分；历史库重跑重挖；注释只写意图。

## 1. 现状

符号落盘已齐：文件、行范围、参数名、参数类型、返回类型、基类、父、深度、签名、文档标记均在库内。调用落盘已齐：被调引用、调用者引用、解析来源、置信度、接收者、函数名、实参数、序号、字节区间、作用域键均在库内。导入边随版本全量刷新。树构建优先用父与种类，缺失回退点分。证据在渲染前联查签名并带入渲染与片段，归纳提示带短签名，健康计数带来源分布。

读侧存在断点：符号详情查询仅归纳内部使用，调用双向查询不存在，导入边两个读方法无任何出口调用，接收者、函数名、实参数、深度、基类写后无读法，同名多类型返回形状不稳定，调用身份仍用实参原文，缓存指纹未覆盖抽取逻辑变更。

## 2. 缺口

符号详情无出口。排错、问答引用、跳转需要按限定名查完整符号，按文件列符号，按父查成员。现有查询只服务归纳，命令行、服务接口、网页接口均无符号视图，库内字段外部拿不到。

调用图走不动。找谁调我、我调谁、某文件全部调用、某调用者上下文是导航与剪枝的基本动作。现有证据按模式分组返回，无法按调用者或被调者直接查，调用者引用已存但无双向边查询，接收者与函数名无法参与过滤。

导入边写后无出口。扇入扇出、跨文件剪枝、内外部分离、循环发现都需要按目标查导入者与按文件查导出。两个读方法已写但三端均未透出，边种类恒为一种，来源语句的形态差异丢失。

同名多类型不稳定。同一限定名可对应多个种类，详情返回按种类分组，证据联查用无排序查询直接覆盖，归纳取首个种类非确定。按名查询的使用者拿到的结果随行序抖动，排错无法复现。

调用身份仍脆弱。身份用实参原文拼接，空白、引号、格式化即变，清扫抖动大。使用者重跑期望收敛，增量期望稳定，原文应用于展示，身份应使用规范形。

缓存失效不可解释。指纹覆盖运行时、语法包版本、查询文本、配置版本与后缀，未覆盖抽取规则文本变更，配置版本从未推进，解码用缺省值掩盖缺字段。抽取逻辑一改，旧缓存继续命中，使用者无法判断何时重解析。

挖掘输入仍窄。频次、共现、序列只吃被调名，重载同名不同元数被合并，不可信调用只能全要或全丢，工厂改写、继承上查、类型回填等来源无法分层统计。使用者需要先可过滤，再按需加权。

签名装配不统一。证据用全行查询，归纳用短签名段，两处参数与返回的取舍不同，完整类型信息在提示中丢失。问答与标签的使用者需要同一装配：全签名、参数名表、返回类型。

健康缺少质量面。现有健康只有模式数、支持总量、复用度、聚类数与来源分布，无置信分布、未解析率、调用者链接率、签名缺失率。运维无法判断是抽取问题还是数据本身稀疏。

## 3. 方案

读模型内补齐四个视图，全部走版本作用域与审核语义。符号视图按限定名批量查完整列，按文件列符号，按父列成员。调用视图按被调查调用者列表，按调用者查被调列表，单文件调用列表带分页，字段含接收者、函数名、实参数、置信度、来源、行与字节区间。导入视图透出已有两个方法，边种类细化为导入形态区分。符号与调用的排序必须确定，同名多类型按种类优先级与签名非空程度排，证据与归纳共用同一装配函数。

调用身份改用实参规范形参与显示分离。规范形做空白归一、字面量掩码、长度截断后进身份，原文仍存库供展示。实体身份保持版本加限定名加种类不变。清扫逻辑随身份走，保持按版本全量对照。

缓存指纹纳入抽取规则文本，配置版本随抽取语义变更推进，解码收紧为缺必填字段即失效重解析。旧缓存整体重解析，不保留兼容分支。进度水位与向量同步语义不变。

挖掘输入先加过滤维度后评估加权。频次、共现、序列的装配支持按置信度、解析来源、实参数过滤，默认行为与现有一致。加权是否进排序单独用夹具对比，不借过滤改动偷换排序。

三端薄透传。命令行加符号、调用、导入子命令，服务接口加同名视图，网页接口加同名查询模型，均只做参数校验与读模型调用加结果透出，不写业务逻辑。健康计数加置信分布、未解析率、链接率、缺签名率。

## 4. 任务

1. 读模型补符号视图、调用双向视图、导入视图透出，统一确定排序与签名装配，文档库表说明同步。
2. 三端透传上述视图，参数校验与分页收敛到现有风格。
3. 调用身份改规范形，清扫随动，综合夹具验证重跑收敛。
4. 缓存指纹纳入抽取规则，配置版本推进，解码收紧，旧缓存重解析验证。
5. 挖掘装配加过滤维度，夹具对比默认结果一致，加权单独评估。
6. 健康计数加质量面，黄金样例与集成用例补齐符号可查、双向可走、扇入扇出可查、树归属正确、签名一致、失效重解析。

## 5. 验证

综合仓库重跑后，已知符号的文件行、参数类型、返回类型、文档标记可查；已知调用的来源可解释且调用者引用非空；按被调与按调用者双向查询互为逆；导入边扇入扇出符合已知导入集合；特征树已知类分支按真父子挂载；同名多类型多次查询顺序稳定；格式化后调用身份不变；抽取逻辑变更后缓存失效重解析；默认过滤下序列、频次、共现与改前一致。

## 6. 非目标

不做跨函数数据流，不做实参语义归一化到执行等价，不做向量与问答主路改造，不做旧库旧缓存兼容，不做版本升级与发布动作。
