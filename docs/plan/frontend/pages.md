# 页面级功能清单

> 每个页面列出目标用户动作、必需控件、空态与降级。后端字段语义以 OpenAPI 为准，
> 此处只写前端必须呈现的信息维度。

## 搜索页（核心，最高优先级）

- 搜索框加三维限定：库名、版本、生态，以及检索档位（precise/balanced/thorough）与条数。
- 结果列表展示标题、库版本归属、地址与片段，支持按分组去重后的顺序浏览。
- 状态区必须呈现可回答性（answerable 与 answerability 数值）、降级标记（degraded）与原因列表（reasons），
  向量不可用时明确提示已降级为纯全文单路。
- 零结果且开启联想时，展示 registry 联想建议（suggestions）与联想失败提示（suggest_error）。
- 空态区分三种：未搜过、搜过无结果、无证据（后端返回空但 answerable 为假）。
- 每个结果提供直达问答页与文档阅读器的入口。

## 问答页（ grounded 回答）

- 与搜索页共享限定条件，调用问答端点生成带引用的回答。
- 回答区展示正文、置信度（confidence）、模型名（model）与引用列表（citations/cited_ids），
  引用可点击跳转到文档阅读器对应位置。
- 无可用证据时展示空回答与原因（reasons），禁止编造引用；LLM 未启用时提示配置缺失而非报错堆栈。
- 配额开启时生成可能被拒绝，需展示 429 与重置时间（reset_at），并保留纯检索结果。

## 文档阅读器

- 三种阅读模式：整页（page）、窗口（window，需指定 sort_order 与 radius）、章节（section）。
- 支持按来源组（source_group_id）与库版本过滤定位同一地址的多归属文档。
- 展示块定位信息（标题路径、排序号）与前后兄弟块导航（窗口模式）。
- 地址不存在返回 404 时给出明确的未收录提示，并引导到入库向导。

## 文库目录页

- 无库名时展示库列表，有库名时展示该库版本列表，支持按生态过滤。
- 每个库/版本入口可下钻到搜索页（带预填限定）、文档阅读器与源码洞察页。
- 版本需区分预发布（include_prerelease 开关）与稳定版展示。
- 版本行可打开依赖对话框（`/repo-deps`），展示 ecosystem、名称、版本要求与来源文件；
  空结果与 404/502 分别走空态与错误态。

## API 洞察页

- 四个视图共用一组限定（库、版本、生态、条数）：
  - 用量排行（usage）：API 频次榜。
  - 相关推荐（related）：给定 API 的共现 API，需先输入 API 名。
  - 参数形态（args）：给定 API 的实参形状分布。
  - 共同相关（common）：多个 API 的共同关联，支持逗号分隔多值输入。
- 缺必需参数时前端即时校验，不发请求；API 名支持从调用页与模式页跳转带入。

## 调用页

- 三个视图：按被调方（callee）、按调用方（caller）、按文件（file）。
- 过滤器：是否含模糊解析（include_ambiguous）、解析种类多选（resolve_kinds 逗号分隔）、
  实参数量上下界（min_args/max_args）、分页（limit/offset）。
- 每条调用展示被调名、调用文件、调用者、行范围、置信标签（EXTRACTED/INFERRED/AMBIGUOUS），
  置信标签用颜色区分，模糊项默认折叠或置灰。

## 符号页与导入页

- 符号页四个视图：详情（detail）、所在文件（file）、子符号（children）、签名（signature），
  支持单 API 与多 API（apis 逗号分隔）输入及分页。
- 导入页两个视图：谁导入了它（importers）、该文件导入了谁（imports）。
- 符号详情与调用页双向跳转：符号可查调用，调用可查符号定义。

## 模式页（序列挖掘）

- 七个视图：模式列表（patterns）、证据（evidence）、特征树（tree）、聚类（clusters）、
  健康度（health）、标签（labels）、片段（snippets）。
- 筛选器：模式序列（pattern 逗号分隔）、包含（containing 逗号分隔）、前缀（prefix）、
  按文件去重（dedup）、单文件上限（per_file_limit）、库版本限定与分页。
- 证据视图展示来源实例引用（文件与行范围），支持跳转调用页核验。
- 健康度视图与 `/mining-health` 合并展示：覆盖率、解析分布、质量率异常时标红。

## 入库向导页

- 三步流程仅处理文档抓取：解析定位（resolve，target 固定 docs）、
  探测评估（doc-probe 按起始地址加范围）、正式提交（scrape）。
- 解析结果若为代码仓库地址（如 GitHub/GitLab 仓库路径），向导不将其当作文档站抓取，
  改为引导跳转索引请求页（`/requests`，带 kind=repo 及已解析参数回填），由审批链决定是否入库。
- 仓库发现辅助：registry 搜索（library-search）、网页搜索（web-search）、
  代码仓搜索（github-search），结果可一键填入向导；解析与 registry 搜索均携带预发布开关。
- 提交后返回任务标识并跳转任务中心；目标地址不合规（后端 400）时展示拒绝原因。
- 仓库探测（repo-probe，含 subdir/max_files/only_files/exclude_patterns）保留在索引请求页；
  向导不展示仓库依赖，已入库版本的依赖在文库目录页版本行查看。

## 任务中心页

- 任务列表展示标识、类型、状态、结束时间与错误摘要，支持条数控制。
- 任务详情展示完整结果与错误信息，通用任务（jobs 新建：类型加参数 JSON）提供表单入口，
  取消操作需二次确认。
- 列表页对运行中任务做轮询刷新，完成或失败即停止；取消后状态即时更新。

## 审核页

- 待审列表展示实体标识、被调名、调用文件、调用者、置信度、实参与行范围，
  按置信度排序（模糊优先）。
- 单条操作：通过（approve）、标记冲突（conflict）、重新打开（reopen），
  状态非法流转（后端 409）时提示当前状态而非覆盖。
- 写操作成功后写审计，后端已记录，前端只需展示操作结果。

## 反馈页

- 提交表单：实体类型、实体标识、种类与正文，提交后返回标识。
- 反馈列表支持按状态过滤与条数控制，处理人可标记已解决（resolve），已解决项置灰。
- 从调用页与模式页可一键带入实体信息发起反馈。

## 管理页与全局状态条

- 健康状态条（常驻页眉或状态页）：存活（health 指纹）、就绪（readyz 各检查项：sqlite/vector/embed/chat）、
  进程计数（metrics：请求数、配额拒绝、token 用量、延迟）。
- 密钥管理：列表展示前缀与有效期，支持按租户加角色加权限域签发，吊销需二次确认，
  新密钥只展示一次原文。
- 配置刷新按钮展示新旧指纹，指纹变化即提示。
- 配额策略页签（`admin:config`）：列表展示租户/主体/资源/上限/窗口，支持新增与编辑（PUT），
  上限 0 显示为不限；与 429 提示形成「能拒也能配」的闭环。
- 管理页所有操作均为高权限，无权限时整个页面隐藏而非逐按钮禁用。
