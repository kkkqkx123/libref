# 运维面与非功能要求

> 任务、审核、反馈、管理四个面的操作流程，以及前端必须满足的非功能约束。
> 后端依据：`src/libref/web/app.py` 权限 scope、`src/libref/web/middleware.py`
> 中间件语义、`docs/architecture/frontend-hosting.md` 托管结论。

## 任务运维流程

- 入库提交与通用任务提交统一落到任务中心跟踪，提交返回的任务标识即深链到详情页。
- 详情页展示状态机全貌：排队中、运行中、已完成、失败（含错误原文）、已取消；
  运行中任务展示取消入口，已终态任务不再展示。
- 失败任务提供按原参数重提的快捷入口，重提即新建任务而非复活旧任务。

## 审核流程

- 审核队列按置信度排序消费，模糊优先；单条处理后自动定位到下一条，减少翻页。
- 非法流转（后端 409）展示当前状态并刷新该条，不做乐观覆盖。
- 审核写操作随附审计，后端已记录主体与请求标识，前端透出请求标识便于对账。

## 反馈流程

- 反馈提交后进入待处理列表，处理人标记解决后置灰归档，不做物理删除。
- 反馈可从调用与模式证据一键带入实体信息，保证实体类型与标识准确。

## 系统管理流程

- 密钥签发：填名称加租户加角色加权限域，可选有效期，确认，展示原文一次并复制；
  原文关闭后不可再查，只能吊销重签。
- 配置刷新展示新旧指纹，指纹一致提示无变化，不一致提示已生效。
- 健康状态条常驻展示存活与就绪，就绪降级时整站顶部标黄但不阻断只读浏览。

## 非功能要求

- 鉴权：dev 模式免登录直接使用；enforced 模式凭 API Key 按 Bearer 访问，
  401 即转登录页；公开路径（根路径、产物目录、health、readyz）免凭据加载外壳。
- 权限：按 scope 显示隐藏页面（read、review、ingest:write、jobs:write、feedback、admin），
  前端隐藏与后端拒绝双保险。
- 配额：429 按资源展示本地化后的重置时间并提供手动重试（不做到期自动解禁）；
  静态命中不计数，只有 API 调用计数。
- 可观测：报错展示 x-request-id；审计动作（审核、反馈、任务、密钥、配置刷新）成功后提示已记录。
- 托管：产物目录缺失或缺 index.html 时后端以降级纯 API 运行，前端构建流水线需保证产物完整；
  静态资产长缓存、index.html 不缓存；开发期前端 dev 服务器经 `VITE_API_BASE` 直连本地 8001。
- 技术栈：Vite 加 Vue 3 加 Element Plus，`webui/` 独立 npm 工程不进 pyproject；
  接口契约以 FastAPI OpenAPI 为准，前端不直连任何服务层。
