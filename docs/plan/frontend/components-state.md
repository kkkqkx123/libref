# 共享组件与状态模型

> 跨页面复用的控件、筛选器状态与数据策略，保证全站行为一致。

## 全局限定的筛选器模型

- 库、版本、生态三元组为全局共享状态：搜索页、问答页、洞察各页读写同一份限定，
  切换库时版本自动清空并重新拉取版本列表。
- 检索档位（precise/balanced/thorough）与条数跟随搜索与问答，不带入洞察页。
- 所有逗号分隔多值输入（apis、pattern、containing、resolve_kinds）共用一个标签输入组件：
  输入即切分去空，展示为可删除标签，提交时再拼回逗号串。

## 共享展示组件

- 置信标签：EXTRACTED/INFERRED/AMBIGUOUS 三色徽标，审核页按模糊优先排序。
- 引用块：问答引用与模式证据共用，展示标题、地址、库版本与行范围，点击跳阅读器。
- 状态徽标：任务状态（pending/running/done/failed/cancelled）、审核状态、
  反馈状态共用一套颜色语义。
- 降级横幅：degraded 为真时全页顶部展示原因列表；answerable 为假时问答页展示低证据说明。
- 空态与错误态：未搜索、零结果、低证据、上游 502、配额 429 各有固定文案与下一步引导。

## 数据与刷新策略

- 目录数据（库列表、版本列表）做会话级缓存，入库提交成功后失效。
- 只读洞察页不轮询，翻页与改筛选即重新请求；offset 分页保留已加载页，支持返回不丢失位置。
- 任务中心对运行中任务轮询详情，完成即停；管理页指标按固定间隔轮询，就绪检查只在进入时拉取。
- 写操作（审核、反馈解决、任务取消、密钥吊销）成功后即时更新本地列表，不等待轮询。

## 表单与校验

- 数值输入（limit、radius、offset、min/max_args、per_file_limit）按端点上下界做前端钳制，
  越界即时提示不发请求。
- JSON 参数输入（通用任务 params、探测 scope）提供格式校验，非法 JSON 禁止提交。
- 高危操作（任务取消、密钥吊销与签发、配置刷新）统一二次确认，签发密钥成功后提供一键复制。

## 路由与深链

- 所有页面支持地址栏复现状态：搜索条件、洞察视图与筛选、阅读器地址与模式均可分享直达。
- 页面间跳转带参：搜索结果到问答与阅读器，调用到符号，模式证据到调用与反馈，
  入库向导提交到任务详情。
- 无权限页面整页隐藏并重定向到无权限说明，不做按钮级灰化拼凑。
