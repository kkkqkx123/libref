# 前端样式设计与统一规范

> 目标：全站视觉单一来源，新增页面不发散。做法参考 linkrs 前端
>（设计令牌单源加检查脚本、布局三件套、通用组件分层），
> 组件实现按本项目既定技术栈（Vue 3 + Element Plus）落地。

## 设计原则

- Element Plus 是基础控件的唯一来源，不自造按钮、表格、表单、弹窗；
  自研组件只覆盖 Element Plus 没有的领域表达（置信徽章、引用块、证据列表等）。
- 所有颜色、字号、间距只出自令牌文件，页面与组件内禁止写死色值字号。
- 默认中文：界面文案以简体中文为默认语言，与文档语言一致；Element Plus 默认取中文语言包。
  多语言支持与词条组织见 `i18n.md`。

## 令牌单源

- 建一份 CSS 变量令牌文件，承载品牌色、语义色（主要、信息、成功、警告、错误）、
  置信三色（已提取、推断、模糊）、状态色（任务、审核、反馈）、
  表面与文字灰阶、圆角与阴影。
- 排版节奏同样出自令牌：字阶 `--fs-*`（12/13/14/18/20px）、间距 `--sp-*`
  （4/6/8/12/16/18/20/80px）集中在令牌文件；组件与页面的字号、间距、
  内外边距只引用变量，不写死 px。宽度用 `.libref-w-*` 工具类，不写内联 `style`。
  元素的 `width`/`height`/`min-width`/`max-width` 与 `1px` 边框属布局细节，可用字面值。
- Element Plus 主题变量从令牌映射，不在多处重复定义；明暗两套值同文件管理，
  深色模式沿用 Element Plus 的暗类切换，主题选择持久化到本地。
- 配一个令牌一致性检查脚本纳入流水线：扫描整个 `src/`（含 `App.vue`）与
  `tokens.css` 的共享工具类区，校验必需令牌在明暗两套存在、Element Plus 映射在位、
  页面引用的字阶与间距令牌均已声明，并禁止裸色值（含函数式与具名色）、
  内联 `style`（含 `:style`）、写死的字号与间距声明，漂移即失败。
  令牌定义区是色值与布局字面值的唯一允许位置。

## 布局外壳

- 顶栏：产品名、健康状态点、库版本限定速览、主题切换、登录态。
- 侧边导航：按六大功能域分组，条目按权限 scope 显示隐藏，无权限页面整页隐藏。
- 页头：标题、说明、操作区三段式，所有页面统一。

## 共用清单

### 共用样式

- 令牌变量文件、Element Plus 全局覆盖、明暗主题、滚动条与代码块排版、
  截断省略与单行标签工具类、打印隐藏类。

### 通用组件（跨域复用）

- 确认弹窗、抽屉、空态、加载骨架、页内加载态、消息提示（用 Element Plus 消息）、
  命令面板（页面跳转与常用操作）、分页封装、标签输入（逗号多值）、
  状态徽章（任务、审核、反馈共用颜色语义）、置信徽章、引用块、
  降级横幅、错误态（含请求标识展示）、健康圆点、键值展示行。

### 业务组件（领域内复用）

- 全局限定的库版本生态筛选器、检索结果列表、阅读器模式切换、
  洞察筛选器组、证据列表、任务轮询器、审核单条操作条、
  反馈带入实体表单、密钥一次展示复制框。

### 全局状态

- 登录态与能力门控（后端角色映射为界面能力：读、审核、入库、任务、反馈处理、
  密钥管理，未知角色默认只读；做法参考 linkrs 的角色能力映射）、
  全局限定的筛选器、目录缓存、主题、通知。

## 统一手段

- 新增页面先查共用清单，有现成即复用，缺失才新增并回填清单。
- 令牌检查脚本、契约类型生成、组件清单评审三道门禁，保证样式与接口双不漂移。
