# MCP 文本格式与精简边界标记修改方案

现状来自对九个工具返回文本的实测。包络层已经统一，剩余问题集中在文本字段内部：纯文本、清洗后 Markdown、原始源码摘要混用，边界靠换行拼接和行内符号标记，截断与缺省各自为政。

## 现状盘点

检索命中以纯文本摘录为主。正文先去标记再按查询词切窗口，命中用行内符号包裹，前后用省略号连接。同一命中还带有 Markdown 尾巴和词表，窗口展开又是去标记纯文本，一条命中混了两种方言。

精读返回清洗后 Markdown。同一页面按顺序拼接，块明细又重复一遍正文，靠换行隐式分隔，没有显式块边界。窗口按行号取相邻行，可能混入全文清洗变体，与整页方言不一致。

问答材料是截断后的 Markdown，标题加地址加正文拼成编号块，截断只认行边界不认围栏。问答输出是自然语言，定位键只在引用结构里，正文里没有可机读的回指。

挖掘与审核返回代码符号加有损参数摘要。容器记省略形式，嵌套调用只留函数名，未知记问号，长度截断。证据按作用域整组返回调用序列，模式在序列中的间隔没有标记，看不出哪些调用相邻、哪些隔了多远。

目录、任务、解析只有短串和地址，没有正文。其中目录描述是注册表原文，未做规范化。

## 借鉴对象

对标编排包查询接口的做法可取三点。第一是统一入口加共享服务：多种检索统一走一个协调者，HTTP 与 MCP 共用同一服务与同一条目形状，传输层只差包络。第二是正文原样、元数据进属性：代码与文档正文一律原样放置，文件路径、行区间、名称、关系方向只出现在标签属性里，正文永不转义，属性只转义必要的五个字符。第三是缺省显式化：相邻段合并后中间的省略行用自闭合缺口标记，超预算或文件缺失的正文降级为文件加行区间加原因的引用标记，预算截断在尾部用总数标记，绝不用省略号或空行伪造连续。同一套标签构造同时用于费用估算与实际渲染，整单元取舍不半截，主命中钉住，输出按结构顺序排列，每个片段自带定位。

## 修改方案

总体原则是 JSON 包络不动，只改其中文本字段的组装方式。正文原样，边界用精简标记，缺省显式声明。只改原模块，不建替代模块，不保留旧文本形状。

共用规则先统一。所有面向模型的文本字段共用同一套边界约定：片段用带定位属性的单元标签包裹，正文原样放在标签之间；被合并掉的中间行用缺口标记标出行数与区间；正文被降级时用引用标记给出路径与区间与原因，不给空正文；预算截断用尾部标记给出省略单元数。属性转义与正文原样严格区分，费用估算与渲染共用同一构造，避免量出来与发出去不一致。截断只整单元取舍，不从单元中间剪断，围栏必须成对，破坏围栏的截断一律降级为引用。

检索摘录去掉行内高亮符号。命中摘录改为原样短摘加单元包裹，定位属性带文档编号、块编号、来源分组、页内顺序，命中词位置另起字段或用标签包裹，不再污染正文。重叠尾巴与窗口正文统一方言，不再混用去标记文本与 Markdown。同页多命中按结构顺序输出，缺口用标记标明。

精读拼接去掉隐式换行分隔。整页与整节改为单元序列，每个单元自带块编号与顺序，正文原样。块明细不再重复正文，只给定位与长度，正文只在组装后文本中出现一次。窗口统一只取同一路分块，不再混入清洗变体，保证同一地址两种模式方言一致。

问答材料改为带定位的单元序列。每个材料一个单元，属性带序号、地址、标题、文档编号与块定位，正文原样。超限材料降级为引用标记，尾部省略用总数标记。问答输出的引用编号与材料单元序号一一对应，保证正文引用可机读回指。

挖掘证据补上间隔标记。模式证据不再整组倾倒调用序列，只输出命中子序列及其必要的邻居，命中之间隔开的行用缺口标记标出。每次调用自带文件、行区间与置信，正文即有损摘要本身，不再伪装成完整源码。摘要不可执行的状态保持不变，但调用方能看清间隔与定位，必要时可凭定位回读。

目录描述做一次规范化，与文档管道的空白折叠一致。任务与解析短串保持原样，不引入标记。

## 落地顺序

先收敛共用边界约定与转义规则，再改检索摘录与精读组装，这两处是文本量最大的入口。随后改问答材料组装，保证引用与材料同序。最后改挖掘证据的间隔标记与目录描述规范化。每次只动原模块内组装函数，存储与索引不动。

## 验证

检索摘录不再出现行内高亮污染，正文可直接复制。精读整页按单元切分后仍能完整还原原页面语义，窗口与整页方言一致。问答材料围栏成对，超限材料降级为引用而非半个代码块。挖掘证据可读出命中间隔。验证收敛为少量运行，输出重定向后阅读，不在改动中反复全量编译测试。

## 本次不做

不改检索排序与挖掘算法，不引入分页游标，不做大载荷通用截断。参数摘要保持有损，不恢复完整源码行。包络形状沿用已有统一结论，不在此重复改动。
