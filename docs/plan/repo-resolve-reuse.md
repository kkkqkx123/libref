# 代码索引按库名解析复用仓库地址

> 目标：文档抓取与代码索引双路径均支持只给生态加库名即可工作，代码路径复用注册表已提取的仓库地址，不再要求手写仓库地址。

## 背景

文档路径已支持按名称解析，解析结论含仓库地址并落库。代码路径仍要求调用方显式传入远端地址或本地路径，未读取已落库的仓库地址。两者生态口径也不一致，代码路径缺生态参数，挖掘路径缺生态透传，同名库在不同生态下会写到错误版本分区。

## 范围

只改编排与出口，不改存储结构，不新增迁移。仓库登记、库表、注册表缓存表结构保持不变。抽取引擎、挖掘算法、抓取分块向量逻辑不变。

## 解析优先级

显式传入地址永远优先，其次复用同版本已登记的仓库记录以保证重复执行幂等，再次按库表、注册表缓存、人工覆盖、实时注册表依次查找。实时查询失败时若有过期缓存则降级使用过期结论并标记来源，离线模式只读缓存。自定义生态跳过注册表查找，找不到时明确报错要求显式给地址。

人工覆盖新增可选仓库地址字段，文件覆盖优先于内置覆盖，两者均只低于显式地址。覆盖文件允许只写仓库地址而不写文档地址，以支持无文档站的纯源码库。

版本未指定时取注册表稳定版，无稳定版时过滤预发布后缀后按版本比较取最大，仍无版本则明确失败。指定版本时不校验是否在注册表版本列表中，代码版本标签与发布版本可能不一致，只透传确认标记。

## 归属划分

注册表子包只负责各生态负载解析与地址卫生，不读写库。解析服务负责覆盖加缓存加实时查询，是唯一读写注册表缓存的位置，新增仓库地址解析入口，与文档解析入口共享缓存读写与版本选择逻辑。编排层负责先查本地仓库登记与库表，再调解析服务补全缺失地址，最后执行原有克隆遍历抽取落库流程。出口层只做参数解析与服务调用。

## 出口变化

命令行代码索引新增生态参数，远端地址改为可选。显式地址与按名解析互斥，同时给出视为用法错误。按名解析时版本号可选，缺省取稳定版。异步任务在提交前完成解析，任务参数中记录解析后的地址、生态、来源与确认标记，保证任务可重放，工作线程不再做网络解析。

挖掘命令新增生态参数并透传到底层版本定位，避免跨生态串版本。检索与问答入口无需变更。

只读解析工具新增仓库地址解析入口，不触发抓取与索引，供调用方预检地址可用性。

## 验证

离线注入传输断言按名解析出期望仓库地址与版本、显式地址优先、已登记记录优先于注册表、缓存命中不产生网络请求、离线缺缓存明确失败、仓库兜底不进文档抓取队列。端到端以迷你本地仓库验证显式路径回归，以模拟注册表验证按名路径落库分区正确。
