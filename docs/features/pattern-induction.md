# 模式归纳链路实现说明

> 范围：聚合层语义归纳，不做逐文件抽取；结构事实留给静态挖掘，模型只做命名描述。

## 定位

归纳对象为版本内已落库的序列模式，按支持度取前若干；输入为聚合后的模式加形态加共现加作用域，不含源码原文与字面量；产物为展示与问答增强用的语义标签，不做排序主键。

## 数据来源

模式来自序列模式表，按支持度倒序截断；形态来自调用实例按接口分组的实参分布，共现来自同作用域共现查询；两类上下文均按模式内全部接口分别采集后合并截断，透传待定开关，与挖掘口径一致；审核冲突的调用不进入归纳上下文。

## 输入构造

归纳输入含模式序列、支持度、形态列表、共现列表、作用域文本；形态条目携带所属接口名加实参加计数，提示词按接口逐条渲染归属；作用域按库版本生态组装，有值展示，无值省略；形态与共现各截断保留前六，排序确定。

## 提示词与传输

提示词为系统加用户两条消息，要求纯结构化输出，字段收敛为名称、摘要、类别路径、工作流、关联接口；类别要求从接口点分名称派生词汇，从粗到细至多四层；关联接口必须从模式加共现构成的允许集合中选择，提示词显式列出该集合。

传输复用统一网关的问答函数，共享重试加熔断；请求固定零温度，非流式与流式两路一致；未开启问答、模型为空或密钥缺失时返回空，归纳直接抛配置错误；问答密钥缺省时回落到嵌入密钥。

## 校验与持久化

输出先解析为对象，再经数据模型校验必填与长度，类别路径清洗去空并限深，关联接口去重截断；白名单校验拒绝版本外的关联接口；边界标记检查拒绝携带材料边界标记的载荷，失败计入计数，不写半成品。

标签单独存表，字段含模式哈希、模式原文、模型、提示版本、名称、摘要、类别路径、工作流、关联接口、更新时间；幂等键为版本加模式哈希加模型加提示版本，命中跳过；写入按批量提交，中断后已完成批次可续；增量挖掘同步清理已消失模式的标签，全空时按版本清空。

## 编排与出口

编排入口按库版本生态加候选上限加待定开关组织任务参数，支持同步与任务队列两种驱动；任务消费者只处理归纳任务类型，参数透传；命令行提供归纳子命令，支持同步执行与异步入队，参数只做透传。

## 读取与消费

读取按版本过滤，支持包含过滤与条数截断；按更新时间倒序，同一模式哈希只保留最新一行，截断作用于去重后结果；缺表时返回空，不抛错。

问答编排取少量标签作为额外材料，与检索段落同属边界标记单元，标签名与模式走属性转义，正文截断后直写；标签只做展示增强，不参与排序与引用定位。

## 配置与密钥

归纳开关默认关闭，候选上限、批量大小、提示版本有默认值；问答模型、基址、超时、思考开关复用问答四件套；密钥经环境变量注入，不入库不进文件，日志只打脱敏快照。

## 测试与边界

单测锚定模式哈希稳定、提示词不含源码、形态归属与作用域渲染、允许集合展示、白名单拒绝、边界标记拒收；集成用例覆盖片段可执行、去重分布、标签幂等跳过与问答增强；大候选上限需调用方显式提高；并发归纳、受控类目表、服务端结构化输出、用量记账不在本链路范围。
