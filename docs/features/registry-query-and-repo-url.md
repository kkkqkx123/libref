# 各语言库查询与仓库地址获取方式

本文说明按名查询六个注册表生态时，版本号、文档地址、仓库地址分别从何而来，
以及仓库缺失时的处理与替代方案。状态为当前实现，以真实网络端到端验证为准。

## 查询入口与结论

统一经注册表解析服务，两种目标：文档解析返回文档地址与仓库地址，
仓库解析只要求仓库地址。结论含生态、归一化名称、版本、是否经注册表确认、
文档地址、候选地址、主页、仓库地址、来源。解析优先级为显式地址优先，
其次复用已登记的仓库记录与注册表缓存加手工覆盖，最后才请求实时注册表。
离线模式只读缓存，实时失败且有过期缓存时降级使用并标记来源。

## 总览

| 生态 | 对应语言 | 版本真源 | 文档地址来源 | 仓库地址来源 | 备注 |
|---|---|---|---|---|---|
| pypi | python | 包元数据的版本与发行列表 | 工程地址中文档类链接优先，主页兜底 | 工程地址中源码类链接，跳过赞助类 | 文档与仓库同一次请求 |
| npm | javascript、typescript | 版本标签的最新版与版本表 | 主页，非仓库根才收录 | 仓库声明字段，兼容字符串与对象形态 | 文档与仓库同一次请求 |
| crates | rust | 版本列表过滤撤回版，稳定版优先用接口给出的最大稳定版 | 注册元数据的文档地址优先，缺失回退到版本文档站 | 注册元数据的仓库字段 | 文档与仓库同一次请求 |
| go | go | 代理的最新版接口加版本列表 | 按模块与版本派生的模块文档页 | 优先用最新版接口的来源信息，无来源时托管域名按前三段合成 | 文档地址为派生规则，无需请求 |
| maven | java、kotlin、groovy | 版本元数据的发布版标记与版本列表 | 工程对象模型的工程地址，另补版本文档站 | 工程对象模型的代码管理地址并清洗 | 需两次请求，先元数据后选定版本的模型文件 |
| nuget | csharp | 注册时间线按顺序取最新非预发布版 | 时间线最新的工程地址，缺失回退到包页面 | 优先用稳定版包清单的仓库声明，缺失时工程地址为仓库根则提升 | 需两次请求，注册索引加包清单 |

## 分生态说明

- Python 查询包索引的包页面，一次请求同时得到版本、文档候选与仓库地址。
文档候选按文档、变更记录、主页的顺序收录，仓库根地址永不进入文档候选。
- JavaScript 查询包注册表的包文档，一次请求同时得到版本、主页与仓库地址。
文档候选只收主页，仓库地址单独返回。
- Rust 查询箱子接口，一次请求同时得到版本、文档、仓库。版本列表排除撤回版。
稳定版优先采用接口声明，无声明时按版本比较取最大。
- Go 查询模块代理两次，最新版接口定稳定版，版本列表补全时间线。
文档地址按模块与版本派生。仓库地址先取最新版接口的来源信息并清洗，
无来源时仅对常见托管域名的模块按前三段合成，其余如实返回空。
- Java 查询中央仓库两次，先版本元数据定版本，再取选定版本的工程模型文件。
文档候选取工程地址，仓库取代码管理地址并清洗协议前缀。模型文件不可达时
文档与仓库均为空，由上层按缺文档处理。
- C# 查询注册索引加包清单两次。版本按时间线取最新非预发布版。
文档地址取时间线最新的工程地址。仓库地址优先取稳定版包清单的仓库声明，
清单缺失或无声明时，若工程地址本身为仓库根则提升为仓库地址。
自定义镜像下跳过清单请求，不向公共地址泄漏包名。

## 仓库缺失时的行为与替代方案

| 情形 | 行为 |
|---|---|
| 文档解析缺文档地址 | 明确报错并附主页与仓库线索，不进入抓取 |
| 仓库解析缺仓库地址 | 明确报错并附主页线索，不伪造地址 |
| 私有或内网包 | 走手工覆盖文件或显式源，不扩展自动推导 |
| 无文档站的纯源码库 | 覆盖文件允许只写仓库地址，文档缺席不阻断代码索引 |
| Go 变体路径无来源信息且非托管域名 | 如实返回空，需显式源或手工覆盖，后续可按需追加变体导入元标签解析 |
| 批量场景 | 先缓存快照再解析，避免重复请求注册表与清单接口 |

| 层级 | 覆盖内容 |
|---|---|
| 单测 | 各生态名称归一、载荷解析、Go 来源直取与域名合成、NuGet 清单优先与工程提升 |
| 集成 | 离线传输下六生态文档解析与仓库解析的版本、文档、仓库结论 |
| 端到端 | 真实网络下六生态代表包的文档解析与仓库解析双入口，断言版本、文档、仓库非空且仓库指向托管域名，网络失败按环境不可用跳过 |

代表包：Python 用 httpx，JavaScript 用 express，Rust 用 serde，
Go 用托管模块 cobra，Java 用 spring-core，C# 用 Newtonsoft.Json。
