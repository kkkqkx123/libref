# 仓库地址解析与获取失败

本文说明代码仓库地址如何解析、仓库如何获取，以及各环节失败时的行为。状态为当前实现。

相关代码：解析编排在 `services/registry/resolver.py`，快照与清洗在 `crawler/registry/__init__.py` 及各生态模块，手工覆盖在 `crawler/registry/overrides.py`，获取与登记在 `astminer/repos.py`，索引入口在 `services/code/code_ingest.py`（含 `repo_source.py`），命令层在 `cli/code_commands.py` 与 `cli/registry_commands.py`。

## 解析优先级

仓库解析（`target=repo`）与文档解析共用同一套上下文组装，只在最后组装结论时分叉。优先级从高到低为：

1. **显式源**：命令行或接口直接给出的远端地址或本地目录。不经过注册表，要求必传版本；本地目录以存在为准直接采用，不校验远端可达性。
2. **手工覆盖**：外部覆盖文件命中优先于内置表，内置表当前为空。命中按目标收敛：文档解析只看文档覆盖，仓库解析只看仓库覆盖；命中即采用，不再请求注册表。
3. **已登记记录**：索引阶段的查找顺序为覆盖、 `repos` 表（本地路径存在优先，否则用登记地址）、`libraries.repo_url`、注册表缓存；注册表缓存回退查有效期，过期不再采用。
4. **注册表缓存**：新鲜缓存直接复用；实时失败且有过期缓存时降级为陈旧来源（`registry-stale`，有覆盖时记 `override-stale`），唯独“仓库目标下覆盖与缓存均无仓库地址”时不降级，仍明确报错。
5. **实时注册表**：按生态取快照，成功后写入缓存（预发布查询不写缓存，避免污染默认结论）。

显式源与按名解析互斥：给出显式源时不得再传生态，生态固定记为 `custom`，来源记为 `explicit`。

## 仓库地址提取规则

所有地址统一经清洗：只允许 HTTP 与 HTTPS，剥离 `git+` 前缀并转换 `git://`，默认丢弃内网与私有地址（`registry_allow_private` 打开后保留）。仓库根地址永不进入文档候选。

| 生态 | 仓库来源 |
|---|---|
| pypi | 工程地址中源码类条目优先，跳过赞助类条目，只收录已知托管域 |
| npm | 仓库声明字段，兼容对象与字符串两种形态 |
| crates | 注册元数据的仓库字段 |
| go | 最新版接口的来源信息优先；无来源时仅对常见托管域名的模块按前三段合成，其余如实返回空 |
| maven | 工程模型文件的代码管理地址并清洗协议前缀；主页只取工程根的直接子地址，发布版标记只在版本管理节点下查找；模型文件不可达时文档与仓库均为空 |
| nuget | 稳定版包清单的仓库声明优先，清单缺失或无声明时工程地址为仓库根则提升；自定义镜像下跳过清单请求，不向公共地址泄漏包名 |

版本选择与文档解析一致：指定版本优先并标记是否经注册表确认；未指定时取稳定版（nuget 按版本比较取最大非预发布版，而非时间线末位），无稳定版时按版本比较取最大；勾选预发布时比较最大值直接胜出。仓库缺失独立为 `no_repo` 错误（不再复用缺文档种类），提示附主页、已知文档地址与候选，不伪造地址。

生态推断规则：显式生态经别名归一并校验（pypi 禁 `@` 开头，maven 须为 `group:artifact`）；裸名不猜测，只有 `@域/`、冒号、斜杠三种形状可推断，其余必须显式传生态。

## 手工覆盖

覆盖文件为 JSON 数组，每条至少含文档地址或仓库地址之一，附校验日期与来源。键为（生态、归一化名）精确匹配，无模糊命中。文件按修改时间按需重载，内置表与文件层合并后文件优先。文件缺失时告警并继续，不阻断缓存可服务的解析。校验日期过期或格式非法视为陈旧，由持续集成门禁提示重新验证，不自动降级。

## 仓库获取

`RepoManager.ensure` 行为：

- 空源直接报错；本地已存在目录直接采用，属版本库则记录真实提交，否则记 `local`。
- 远端目标固定为仓库目录下的 `生态/库/版本` 子路，含路径穿越校验；已存在且含版本库时可选拉取更新；存在但非版本库时，空目录清理后重克隆，非空目录报明确清理指引；其余情况浅克隆（深度为一）。
- 克隆、拉取、取提交失败均包装库名或地址后上浮，不裸奔。
- 成功后记录远端地址、提交标识、本地路径到 `repos` 表；提交标识取版本库头指针。

文件枚举规则：按后缀过滤源码文件，跳过版本库目录、依赖目录、构建产物、测试相关路径与生成文件，跳过符号链接与超大文件，结果排序保证确定性。

索引入口流程：解析或显式得到源地址后，确保库版本行存在，检查磁盘配额，校验同版本异源（比较前归一化，`git+` 前缀与尾斜杠差异视为同源；换源直接拒绝，需换版本或清理），随后收集解析、持久化实体与调用、校验清单身份（不一致仅告警不阻断）、刷新清单依赖、切分源码块并做向量同步。同版本全程持版本锁，文档与代码写入互斥。

索引前的源查找（`lookup_index_source_cached`）按序尝试：覆盖、 `repos` 表（本地路径存在优先，否则用登记地址）、`libraries.repo_url`、新鲜注册表缓存；皆空且无显式源时在建库前报错，提示用显式地址或带生态按名解析。

## 获取失败分类

| 环节 | 失败 | 行为 |
|---|---|---|
| 按名解析 | 包不存在 | 报不存在错误，附带模糊发现与显式源两条后续 |
| 按名解析 | 网络异常、限流、服务端错误、离线缺失、全源不可达 | 报可重试错误，附带稍后重试或暖缓存重跑 |
| 按名解析 | 注册表无仓库地址 | 报 `no_repo` 错误，附主页、已知文档地址、候选与托管搜索、显式源、覆盖文件三条后续，不伪造地址 |
| 按名解析 | 离线且无缓存 | 报可重试错误，不触网 |
| 参数 | 缺版本、生态与显式源并用、未知生态、非法名称、非法地址 | 参数错误，命令行退出码为 2 |
| 索引前 | 源未知 | 建库前报错，提示显式地址或带生态解析 |
| 索引前 | 同版本异源 | 拒绝覆盖并报错；归一化后等价视为同源 |
| 克隆拉取 | 远端不可达、鉴权失败、公共镜像限流 | 版本库异常包装库名或地址后上浮，不转义为注册表错误；同步模式命令返回 1，异步任务标记失败 |
| 索引前 | 残缺目录（存在但非版本库） | 空目录自动清理后重克隆，非空目录报清理指引 |
| 私有内网 | 地址被清洗丢弃 | 视为无仓库地址，需显式源或打开私有地址开关 |
| 清单 | 模型或清单不可达、不可解析 | 对应字段置空或依赖数为零，不阻断索引 |
| 身份 | 检出清单声明的身份与请求不一致 | 仅告警并继续 |

命令层映射：参数错误打印 `invalid` 并退出码为 2；注册表错误打印分类、上下文（生态、名称、请求版本、主页、仓库、文档地址）与后续操作并退出码为 1；同步索引未知异常打印 `failed` 并退出码为 1，不打堆栈；发现失败同理。异步任务失败时任务状态记失败并保留错误信息，可经任务查询查看。

## 分支覆盖

| 分支 | 行为 | 信息保留 |
|---|---|---|
| 显式源 | 不经注册表直接采用 | 足够；来源记 `explicit` |
| 文档覆盖命中 | 文档解析采用，来源记 `override` | 足够；仓库覆盖不污染文档归因 |
| 仓库覆盖命中 | 仓库解析采用，来源记 `override` | 足够；文档覆盖不污染仓库归因 |
| 新鲜缓存 | 直接复用 | 足够 |
| 实时成功 | 写入缓存（预发布查询除外） | 足够；版本、确认标记、文档、候选、主页、仓库齐全 |
| 实时失败加过期缓存 | 降级为陈旧来源 | 足够；来源后缀区分陈旧，缺仓库且无覆盖仓库时仍报错 |
| 包不存在 | 报不存在错误 | 足够；上下文齐全，可走模糊发现 |
| 缺文档 | 报 `no_docs`，附带主页、仓库、候选 | 足够 |
| 缺仓库 | 报 `no_repo`，附带主页、文档地址、候选 | 足够；调用方可先抓文档 |
| 离线 | 只读缓存 | 足够 |
| 覆盖文件缺失 | 告警并继续 | 足够；缓存可服务的解析不受影响 |
| 索引前查找 | 覆盖优先，缓存查有效期 | 足够；来源标记出处 |
| 同版本异源 | 拒绝并报错 | 足够；归一化避免误伤 |
| 本地版本库 | 记录真实提交 | 足够；调用溯源完整 |
| 残缺目录 | 空恢复、非空指引 | 足够；不静默覆盖用户数据 |
| 清单缺失或身份不一致 | 置空或告警继续 | 足够；不阻断索引 |

## 存储与配置对照

| 对象 | 作用 |
|---|---|
| `registry_cache` | 注册表快照缓存，仓库解析的降级来源之一 |
| `libraries` / `versions` | 库版本目录，`repo_url` 与确认标记随索引写入 |
| `repos` | 仓库登记（名、地址、提交、本地路径），源查找第一优先级 |
| `discovery_cache` | 发现候选缓存，失败时的结构化后续指向此处 |
| `registry_overrides_file` | 外部覆盖文件路径，未配置则只用内置表 |
| `registry_offline` / `registry_cache_ttl_days` | 离线开关与缓存有效期，控制是否触网 |
| `registry_allow_private` | 是否保留内网私有地址 |
| `registry_mirror` / `registry_bases` | 镜像预设与逐生态基址覆盖；国内预设仅覆盖部分生态，其余回退默认基址 |
| `repos_dir` / `repos_quota_mb` | 仓库工作区目录与配额，配额超限在克隆前拒绝 |
