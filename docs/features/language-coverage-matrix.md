# 语言特定内容覆盖矩阵

对象是源码抽取链路中按语言分层的实现，状态截至本次补齐后。
本表是后续修改的直接依据：凡未完整实现，一律在总览与分语言表中标记，
缺口细节只在缺口汇总一节描述，分语言表仅引用编号，不重复解释。

## 状态定义

完整指该层满足抽取规范且有断言覆盖，无已知缺口。
部分指该层可用但存在已编号缺口，缺口见缺口汇总一节。
缺失指该层整体未实现。
判定口径：语言本身无该形态时不记缺口，例如脚本方言无类型体不记缺口，
类型脚本缺失记为独立缺口；按规范有意裁剪的内容不记缺口，
集中在维持现状一节说明理由。

## 维持现状

下表内容有意不做修改，后续如需重议，先更新本节理由再立新缺口，
不直接按缺口实现。

| 编号 | 范围 | 内容 | 理由 |
|---|---|---|---|
| W01 | go 调用 | 泛型实例化调用未抽取 | 实例化与下标在语法上不可区分，逐个捕获会把全部下标记为调用 |
| W02 | rust 调用 | 宏定义体内部不展开 | 宏体属于定义体展开，与调用抽取无关 |
| W03 | csharp 调用 | 委托调用与直接调用同形不区分 | 同形区分需要类型信息，超出当前两遍解析能力 |
| W04 | rust、java 依赖 | 类型约束与类型引用不进查询子集 | 抽取引擎无对应消费方，按规范裁剪 |

## 新增语言对照清单

登记前逐项确认：四段查询可编译；实体覆盖声明、继承、方法归属；
调用覆盖直接、成员、链式且接收者可拆分；依赖覆盖导入、通配、别名；
注释覆盖行与文档；别名覆盖末段与通配丢弃；
模块路径覆盖源码根剥离；消歧覆盖标准库前缀；
清单覆盖模块标识；夹具覆盖最小形状与空源。
对照中发现的新缺口按上表格式编号记入缺口汇总，
维持现状的裁剪记入上表并写明理由，不保留过渡逻辑。
