# 特征挖掘功能总纲

本文是特征挖掘唯一总纲，描述四层特征模型的定义、构建语义、参数依据与质量标准。索引链路、模式归纳、工具契约等文档只保留摘要并指向此处。

## 四层特征模型

| 层 | 名称 | 输入来源 | 事实性质 |
|---|---|---|---|
| F1 | 结构统计特征 | 调用实例聚合后的归属链 | 静态事实，可复现 |
| F2 | 用法形态特征 | 调用实例的实参、调用形态、样本内序位 | 静态事实，可复现 |
| F3 | 约束守卫特征 | 同一样本作用域内的调用共现 | 语法级近似标注，不做数据流分析 |
| F4 | 语义归纳特征 | F1 到 F3 的聚合结果加模型归纳 | 模型产物，可整体重建，不入真源统计 |

四层全部按挖掘档案隔离。F1 到 F3 落派生表，真源仍是调用实例；F4 单独存表，可删除重建。

## 结构统计特征

特征树优先按符号表的父与种类挂载，缺失时回退到按点分推导，保证包与类层级不混淆。调用数沿父链累加，作用域数按样本键去重。同一档案内路径唯一，幂等写入后按集合差清理消失路径。

聚类按作用域集合求交并比，达到阈值的边连通为一组。代表成员取覆盖作用域最多者，同分时按名称排序，保证确定性。低于最小规模的分组直接丢弃，不落表。

参数依据：交并比阈值默认零点一五，兼顾共现召回与分组纯度；调高阈值分组变碎，代表性下降；调低阈值分组合并，解释性下降。最小规模默认二，单例不成组。两种失效都表现为分组数与多样性指标的单调变化，可在健康视图中直接读到。

## 用法形态特征

形态层收敛为三类维度，全部存入形态派生表，同档案下维度加取值唯一：

- 实参形态：调用实参经掩码归一后的形状分布，掩码保留关键字与字面量种类，不保留具体值。
- 调用形态：调用实例上已有的调用关系种类，按接口区分。
- 调用序位：样本内按位置排序后的三分桶，首、中、尾。

候选组合将实参形态与调用形态按接口交叉，规模受候选预算上限封顶。选择按贡献占比过滤接近零的候选，再按每层截断保留前若干。选择只决定哪些形态值写入派生表，不改变真源。

参数依据：每层截断默认五十，候选预算默认五百，贡献阈值默认零。预算与截断保证写入规模有硬上限；阈值用于剪掉长尾噪声，调高会损失稀有形态，调低会放大派生表。

## 约束守卫特征

守卫层只做语法级近似，不做数据流分析，默认关闭。收敛为三类取值，写入同一形态派生表：

- 配对使用：同一样本作用域内开启与关闭、申请与释放等动词配对出现，且共享同一归属前缀。
- 检查后使用：同一作用域内先出现检查类调用，后出现同前缀目标调用。
- 异常包裹：当前调用记录只有行信息，无法判定包裹关系时直接缺席，不写猜测值；守卫层因此只有前两类取值，没有独立的包裹结构标签。

不可判定时直接缺席是硬规则。宏密集库在覆盖不足时沿用宏覆盖率口径标注限制，不把缺失说成结论。

## 语义归纳特征

归纳对象只限聚合后的特征与分组，不含源码原文。模式标签覆盖序列模式，分组标签覆盖聚类成员，特征树节点本身不做语义命名。分组标签复用模式标签的提示词与校验形制，另收紧两条：关联接口必须落在版本实体集合内；来源说明为必填字段，凡含参考项目语料的分组必须写明场景来源与非官方推荐声明。

归纳幂等键命中直接跳过，批量提交后可续跑。挖掘清理消失分组的标签。归纳开关默认关闭，无密钥时直接报错而非静默跳过。

## 质量标准

- 复用度：模式支持总量的对数形态，反映模式被重复使用的强度。
- 多样性：有效分组数的对数形态，反映特征覆盖的广度。
- 覆盖率：单特征作用域数占档案总作用域数的比例。
- 提升度：形态在归属接口上的出现率相对全档案出现率的偏离程度，高于一表示形态与接口正相关。
- 集中度：单特征调用数占同维度总调用数的比例。

复用度与多样性是健康信号，不是排序主键。检索加成按健康门禁封顶，弱复用时自动收缩加成权重。特征选择生效前后，检索评测的召回与排序指标不得回退。

## 消费规则

读模型提供形态浏览、特征摘要、分组标签浏览与档案对比。问答侧目前只取模式语义标签作展示增强材料，语义类别路径与名称不参与排序与引用定位。检索侧形态命中加权只作用于融合后头部，加成关闭时跳过加载，行为退化为纯融合排序。

## 评测基准

黄金集以官方示例为主构造小规模人工标注语料，标注维度真值与代表性模式。标注只覆盖形态层，不标注语义好坏。差异用例断言改造前后特征分布变化可解释。待审未解析调用不进入黄金真值。
