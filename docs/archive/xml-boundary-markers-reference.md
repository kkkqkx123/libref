# 工具返回边界标记参考基线

时间：2026-11-10（UTC）。对象：工具返回中的类 XML 边界标记全套逻辑。用途：后续改造的对照基线，避免误改原始设计。

判定口径：包络与载荷异语系隔离；短属性串转义，长正文原样；防误用优先于简短；无历史兼容包袱。

## 一、位置与分工

* 唯一真相来源为文本成形叶子中的摘录模块，上层禁止各自拼串。
* 页面组装只负责块单元与文档包络，问答材料只负责编号单元与消息包络，挖掘证据只负责调用序列渲染，三者均调用叶子，不自带转义。
* 结构化引用与定位明细走独立数据通道，不从标记文本反解析。

## 二、当前词汇与形态

* 包络：文档包络、材料包络，均为首尾成对出现，头部携带定位属性。
* 单元：块单元与调用标签，块单元独占一行包裹原样正文，调用标签行内包裹参数表。
* 摘录：摘录包络配命中标记，命中标记只标查询词，不做语义标引。
* 省略三件套：行间缺口、自闭指针、尾部计数，三者职责不重叠，不可合并为一种。
* 缺口属性为行数加区间，区间名统一为区间语义，令牌数为纯整数，不带约数符。
* 调用标签有独立构造器，与块单元同构，禁止在业务侧手拼。
* 文档包络扩展属性为结构化映射，禁止前导空格字符串拼接。

## 三、核心不变量

* 属性转义只处理双引号语境下必需的三字符，其余字符保持原样。
* 转义名前缀为领域限定，不可去除，包内并存多种异构转义，去前缀即引入歧义。
* 正文一律原样，不转义尖括号与和号，围栏配对由截断侧保证，截断落行边界且尾附缺口。
* 禁止伪造连续符，正文缺失用缺口标记，整批丢弃用尾部计数，不用省略号或箭头。
* 单元头部属性一次写全回读定位，正文出现一次，明细只给定位与长度，不重复正文。
* 证据只渲染命中子序列加必要邻居，跳过段用缺口标出行数与区间。

## 四、冲突结论

* 属性层安全，载荷层概率安全而非保证安全。
* 包络词汇与常见文档词汇无交集，示例文档标签与网页标签均不会恰好命中包络名，这是低冲突来源。
* 自指文档或围栏内恰好书写同名标签仍可混淆，当前以原样可读与令牌成本为由接受该残余风险，已用示例文档往返用例锁定。
* 不去除转义：地址查询串与标题引号会提前闭合属性，依赖模型容错属于掩盖问题的兜底逻辑。
* 不改标记语系：载荷本身即文档格式，包络再用同语系标记只会增大冲突；注释形态的标记本质仍是类 XML，且更长。

## 五、禁止事项

* 禁止转义正文，禁止去除属性转义，禁止恢复区间旧名，禁止令牌数加约数符。
* 禁止新增第二套标记模块，优化只改原模块；禁止按优劣拆分，只按职责拆分。
* 禁止包络扩展走字符串拼接，禁止业务侧手拼调用标签。
* 禁止引入省略号或箭头连续符，禁止明细重复正文。

## 六、同步镜像与核查

* 改动包络或转义时，同改叶子、叶子出口、页面组装、问答材料、挖掘证据三处调用、单元边界黄金样例、集成页面断言、离线格式样本说明与生成器。
* 区间改名需同步样本说明中的缺口描述，令牌形态需同步指针与计数两处。
* 核查收口为格式检查、类型检查、单元与服务集成测试，输出重定向到文件后阅读，禁止反复全量编译。
