# 配置、显式参数、硬编码参考基线

时间：2026-11-09（UTC）。对象：当前 `LibrefSettings` 支持字段、调用显参、刻意保持硬编码的三份清单。用途：后续讨论新增配置时的对照基线，避免重复引入真相来源。

判定口径：全局质量与成本进配置；单次意图走显参；协议语义与单模块内聚行为保持硬编码。

## 一、配置来源与规则

优先级从高到低为命令行显式覆盖、环境变量（含本地注入文件）、配置文件、内置默认值。生效快照冻结只读。

密钥只走环境变量，不进文件：编码密钥、问答密钥、接口令牌。文件内出现直接拒绝。

路径字段缺省为家目录下绝对路径，与启动目录无关；文件中的相对路径按配置文件所在目录解析。

分节文件与顶层字段两形态并存，未知节与未知键直接报错。脱敏快照可序列化，指纹用于比对生效内容是否变化。

## 二、当前支持的配置字段

### 服务与抓取

* 服务：库路径缺省为家目录文档库。
* 抓取：并发四个，请求超时三十秒，重试三次，默认抓取间隔一秒，机器人缓存七天，净化缓存上限五百一十二，请求头为抓取标识。代理与旁路缺省为空，走环境与回环默认。浏览器降级默认关闭。

### 存储与分块

* 向量存储：本地回环地址、集合名、超时五秒。
* 分块：向量路硬限五百一十二、最小一百五、重叠五十；全文路硬限一百五、最小四十五、重叠五；预留比例零点零六。

### 编码、重排、检索

* 编码：模型与维度登记在库，基址为线上推理地址，批大小六十四，无密钥时向量路禁用。
* 重排：模型为默认重排模型，默认关闭，候选三十，取前十，截断五百。
* 检索：倒数融合系数二十，全文与向量权重一与零点五，频率与分组加成零点一五与零点零五，候选与装配倍数三与二，装配下限十，摘要半径六十与上限四百，窗口预览上限三百，全文列权重内容一标题五地址一片段路径三，分组阈值零点一五与最小两项，窗口半径一与默认不扩展。

### 注册表、问答、出口

* 注册表：缓存一天，默认在线，默认不放行私有地址，镜像预设默认，生态基址为三生态公网默认，外部覆盖文件缺省为空，覆盖有效期一百八十天。
* 问答：模型为默认问答模型，默认关闭，基址与密钥可回落编码同值，超时六十秒，默认不启用思考模式，材料预算一千五。
* 接口：默认只绑本地回环，端口与路径为内置默认值，对外暴露前必须配令牌。网页出口同理，默认只绑本地回环。
* 留存：快照默认关闭，快照与仓库目录独立，配额分别为五百一十二与两千零四十八兆，删除日志保留三十天。
* 日志：级别警告，默认只走标准错误，格式为文本或结构化二选一。

## 三、显式参数清单

### 命令行全局

配置文件路径、日志级别、日志文件、日志格式，均为缺省读配置的覆盖项。

### 命令行按命令

* 抓取与刷新：库名、版本、起始地址、生态、离线开关、镜像预设、最大页数、存活预筛、异步开关、跨站与子域开关、前缀后缀与正则黑白名单、最大深度、渲染开关。
* 检索与问答：查询串、库与版本过滤、条数、混合开关、窗口扩展与半径；问答另有材料预算，缺省读配置。
* 阅读：地址、序号、半径、库版本过滤、源分组标识。
* 仓库与挖掘：库名、版本、来源、生态、离线、镜像、更新开关、异步开关；挖掘另有最小支持度、调用剪枝数、最大最小长度、分组阈值与最小项、模糊开关。
* 浏览与治理：前缀、包含接口、条数、实体标识、任务标识、完整输出开关、保留期覆盖。
* 服务：监听地址端口路径，缺省读配置。

### 工具与网页

* 文档工具：全文检索、整页、窗口、整节、库与版本列表，分组浏览、共现、证据、分层特征，条数与半径为显式入参。
* 混合与问答工具：库版本过滤、条数、窗口半径与扩展、材料预算，缺省回落配置，失败返回明确分类。
* 审核与任务工具：待定条数、实体标识、任务标识与条数，解析工具为只读。
* 网页查询参数与工具同语义，条数与半径显式传入。

### 模块内显式默认值

挖掘最小支持度二、最大长度十、最小长度二，调用剪枝缺省为空，集群缺省按配置类默认值求解。分块预算按配置构造，无配置时按配置类默认值求解。

## 四、保持硬编码清单

### 抓取安全上限

站点地图深度三与条数两万、地址令牌长度上限、抓取退避基线与上限、限速上限、注册表重试退避、浏览器渲染超时十五秒。理由：礼貌性上限与内存安全，意图已被并发、超时、重试、间隔、缓存有效期覆盖。

### 内容判定与遍历

文档有效性阈值、仓库跳过目录与文件名规则、单文件体积上限、序列长度截断、关键词数、分块与源码展示截断。理由：与抽取启发式和黄金样例绑定，调整即改质量基准，应走代码加对拍测试。

### 传输与任务内部

编码与重排客户端无配置构造时的结构性回落、重试最大次数与基线、熔断阈值与冷却、任务心跳恢复间隔与等待轮询间隔、结果截断、数据库忙等待。理由：单模块内聚行为或协议语义，非部署意图。

### 语义与换算

状态码分类、私有地址判定、秒日与字节换算、分词正则、哈希与指纹、状态机字符串、观测截断。理由：协议语义或显示行为，配置化只会扩大误用。

### 分页条数

各出口条数默认值为调用方显式可控，不收归全局配置，不做透传空值。理由：避免配置与调用两处真相来源。

## 五、暂缓候选

浏览器渲染超时、任务过期与等待超时随环境与仓库体积变化，语义接近运维超时，后续如需提升为配置再单独决策。本次维持硬编码。
