# 数据库查询两轮决策记录

> 时间：2026-11-10。原始方案文档已删除，本篇只保留结论。
> 现状描述见 `docs/features/db/` 各篇，离线核对见 `tests/e2e/db-query/`。

## 第一轮：审计与修复

按域梳理所需查询后，确认语义问题十八条、性能问题十四条，
均已修复并经离线核对确认。

写入侧：单页与整库入口统一事务边界，各写操作经每连接可重入锁串行；
复用键统一为分路加标题加路径加正文，复用行先暂存负排序号避开唯一冲突；
未变化路径刷新服务端凭证；源码幽灵页按存活文件集清理；
声明调用批量幂等写入，失效按存活集合差分批删除；
歧义与未解析推断调用批量建待审行。

读取侧：过滤转版本标识统一按标识升序；去重键改组优先；
重排只剔除消失行；待审排序截断下推；证据分两阶段剪枝；
模式标签列表限制下推；审核映射失败不再静默放行；
精确与混合分制统一为越大越好；全文自检改行定位探针；
版本漂移重建在查询层先过滤分路。

索引补齐页面地址、文档地址、地址加组、版本加分路、
待审状态、任务恢复六项；连接补同步、临时表、缓存三项预设。

接受不改：确认位每次重写（调用方依赖最新解析结论语义）；
任务持久化结果为摘要形态；元数据块哈希仅信息留存。

## 第二轮：全文作用域下沉

修正第一轮的饥饿假设：截断作用于过滤后的有序集合，
不存在先截断后过滤丢行，旧超取真正补偿的只是去重折叠。

全文读取收敛为单个共享函数：无过滤走数据库排序截断；
有过滤先解析版本集合，只取集合内候选行号与分值，
内存堆取前若干，无全局排序。旧超取的饥饿理由删除，
取数倍率只保留去重折叠补偿。服务层版本解析补升序，
不做跨层合一（存储层不可反向依赖服务层）。

明确否决：版本内独立词频重打分；按版本拆全文表；
全文表加非索引版本列（仍全局扫描且逐行回查更贵）；
模式聚类逐查询缓存（两次索引查询，失效复杂度高于收益）；
诱导共现批量改写（改变提示语义）。
