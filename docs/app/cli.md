# CLI 功能总览

命令行是全量管理入口，覆盖写操作、读操作与运维。实现在 `src/libref/cli/`，参数定义在 `parsers.py`，命令实现分置于 `docs_commands.py`、`code_commands.py`、`registry_commands.py`、`ops_commands.py`，公共装配在 `common.py`。所有命令只做参数解析、服务调用与结果打印，业务逻辑在 `services/` 层。

全局选项作用于全部命令：指定配置文件、覆盖日志级别、日志文件与日志格式。退出码统一为成功零、运行失败一、用法或配置错误二，参数错误打印到标准错误。

## 环境与配置

* 初始化数据库：建库并应用迁移，打印库路径与已应用迁移数。
* 查看配置：打印配置文件路径、配置指纹与脱敏后的有效配置。

## 文档写入

* 抓取入库：显式给库名、版本与起始地址，或按生态名解析后抓取。支持抓取上限、单页指定、断点续抓、存活预检、跨站与子域范围、前缀后缀与正则范围、深度、渲染、链接跟随、查询排序与缓存绕过。支持经任务队列异步执行。
* 版本刷新：复用抓取语义的增量更新入口，参数与抓取入库基本对等，支持同步与异步两种执行方式。
* 本地冒烟：起临时站点验证发现到存储全链，不依赖外部网络。

## 源码写入

* 索引仓库：显式给库名、版本与来源，或按生态名解析仓库地址后索引。支持更新已存仓库、子目录与单文件限定、文件数上限、断点续抓、同步与异步执行。
* 挖掘序列模式：按库与版本重建闭合调用序列、特征树与分组，支持最小支持度、长度区间、保留名前列、歧义调用开关、聚类阈值与调用过滤，支持异步执行。
* 归纳模式标签：调用对话能力为模式生成标签，支持数量上限与异步执行。

## 检索问答

* 混合检索：默认融合召回，精确模式走纯文本单路。支持库、版本、生态与条数过滤，窗口扩展开关与半径按调用透传，空命中时可按需给出注册表建议。
* grounded 问答：混合召回后组装材料并生成回答，附引用、降级标记与模型名，无证据返回空回答。
* 按地址阅读：整页、邻近窗口、整节三种模式，窗口模式要求中心序号，整节模式要求来源分组编号。

## 发现目录

* 模糊发现：按查询词跨注册表发现候选，支持生态限定、条数与预发布开关。
* 显式网页搜索：结果未经核验，使用前需确认。
* 显式仓库搜索：结果未经核验，使用前需确认。
* 类目浏览：无库名返回库列表，给定库名返回版本列表，支持生态限定。
* 地址解析：按生态与名称解析文档或仓库地址，失败返回分类错误与后续动作建议。

## 探查预览

* 探查文档站：只返回站点结构，不落库，支持范围限定与采样条数。
* 探查仓库：只返回目录结构，不解析，支持子目录、文件数上限与采样条数。
* 预览分块：按行区间、字节偏移与标题路径预览文档或源码分块。

## 源码洞察

* 接口视角：频次榜、同现接口、参数形状，按库、版本与生态过滤。
* 序列与结构视角：模式列表、模式证据、特征树、分组、健康、标签、片段。证据视图要求非空序列，去重支持显式开启、关闭与默认三态。
* 符号视角：详情、文件内符号、子符号、签名。
* 调用视角：按被调、主调、文件三向查看，支持歧义开关与调用过滤。
* 导入视角：导入者与文件导入两向查看。
* 仓库依赖：查询某版本清单声明的依赖。
* 健康度量：复用度与多样性信号，接受可选的库、版本与生态过滤。

## 运维

* 向量重嵌与对账：全量重嵌或按集合差修复，缺嵌入配置时直接失败。
* 全文索引重建与检查：重建后报告行数与同步状态，不一致时以非零退出。
* 版本清理与删除记录：删除整版本并记录，支持查看与按保留期清理过期记录。
* 审核：列出待定项或对单实体批准、标冲突、重开，流转失败区分为冲突与参数错误。
* 任务查看：无编号列出最近任务，给定编号返回详情，支持完整结果打印。

## 服务启动

* 启动 MCP 服务：默认标准输入输出，可切换为流式 HTTP，支持回环绑定检查、按需鉴权与工具白名单、黑名单过滤。
* 启动 Web 服务：默认绑定回环，可指定主机与端口，鉴权语义与 MCP 的 HTTP 形态一致。
