# Web 功能总览

Web 出口是只读查询面，另带精简抓取写入。实现在 `src/libref/web/`，路由在 `app.py`，请求形状在 `api.py`。所有路由只做参数校验、服务调用与结果透传，业务逻辑在 `services/` 层。请求参数经由数据模型校验，取值范围与必填关系明确。

健康检查无需鉴权，其余路由统一做令牌鉴权，未携带有效令牌返回未授权，鉴权要求开启但令牌缺失返回服务端配置错误。列表类查询统一使用条目加总数包络，检索另带降级标记。参数错误返回请求错误，资源缺失返回未找到，审核流转失败按冲突与参数错误区分返回，注册表缺地址返回未找到或网关错误。

## 健康与目录

* 健康检查：返回可用标记与配置指纹，不鉴权。
* 类目浏览：无库名返回库列表，给定库名返回版本列表，支持生态限定。

## 检索问答

* 混合检索：默认融合召回，精确模式走纯文本单路。共享查询词、库、版本、生态与条数过滤，混合模式另支持窗口扩展与半径。空命中且要求建议时附带注册表建议与建议错误。
* 模糊发现：按查询词跨注册表发现候选，支持生态限定、条数与预发布开关。注册表失败返回网关错误。
* 显式网页搜索：结果未经核验，使用前需确认，失败返回网关错误。
* 显式仓库搜索：结果未经核验，使用前需确认，失败返回网关错误。
* grounded 问答：混合召回后生成回答，返回回答文本、引用、降级标记与模型名。
* 按地址阅读：整页、邻近窗口、整节三种模式。窗口模式要求中心序号，整节模式要求来源分组编号，缺失返回请求错误，地址无命中返回未找到。
* 地址解析：按生态与名称解析文档或仓库地址，失败按缺地址与网关错误区分返回。

## 源码洞察

* 接口视角：频次榜、同现接口、参数形状。部分视图要求给出接口名。
* 序列与结构视角：模式列表、模式证据、特征树、分组、健康、标签、片段。证据视图要求非空序列。
* 符号视角：详情、文件内符号、子符号、签名。
* 调用视角：按被调、主调、文件三向查看，支持歧义开关与调用过滤。
* 导入视角：导入者与文件导入两向查看。
* 仓库依赖：查询某版本清单声明的依赖，要求给出库名与版本。
* 健康度量：复用度与多样性信号，接受可选的库、版本与生态过滤，直接返回健康对象。

## 治理

* 审核查询：获取待定列表，提交批准、标冲突、重开动作。非法流转返回冲突，缺参返回请求错误。
* 任务查看：无编号返回最近任务列表，按编号返回任务详情，未知编号返回未找到。本出口不提交任务。

## 写入

* 精简抓取：按库名、版本与起始地址抓取入库，为命令行抓取的子集，不含范围限定与断点续抓参数。写入面仅此一处，探查、索引、挖掘与向量运维均不在本出口开放。
