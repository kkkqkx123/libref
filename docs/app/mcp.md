# MCP 功能总览

MCP 出口是只读问答面，共十九个工具。实现在 `src/libref/mcp_server/server.py`，组装时按配置过滤可见工具，未知工具名启动即报错。向量、重排与对话能力在组装处显式建立并复用于检索与问答。所有工具只做参数校验与服务调用，不抛协议层错误，失败以载荷内错误返回。

传输支持标准输入输出与流式 HTTP 两种形态。流式形态默认绑定回环，按配置要求做来源检查与令牌鉴权。工具可见性由允许名单减去拒绝名单决定，缺省全部可见，空允许名单表示零工具。

错误分类统一为参数错误、未找到、冲突、不可用、网关错误与失败，必要时附带提示信息。列表类返回条目加总数，检索与问答附带降级标记，检索在空命中且要求建议时附带注册表建议。

## 检索问答

* 混合检索：默认融合召回，精确模式走纯文本单路。共享查询词、库、版本、生态与条数过滤，混合模式另支持窗口扩展与半径。空查询与越界分页直接返回参数错误。
* grounded 问答：混合召回后生成回答，返回回答文本、引用、降级标记与模型名。对话能力缺配置时返回不可用原因。

## 阅读目录

* 按地址阅读：整页、邻近窗口、整节三种模式。窗口模式要求中心序号，整节模式要求来源分组编号，缺失返回参数错误，地址无命中返回未找到。
* 类目浏览：无库名返回库列表，给定库名返回版本列表。

## 发现解析

* 模糊发现：按查询词跨注册表发现候选，支持生态限定、条数与预发布开关。注册表失败返回其分类错误。
* 显式网页搜索：结果未经核验，使用前需确认，失败语义与模糊发现一致。
* 显式仓库搜索：结果未经核验，使用前需确认，失败语义与模糊发现一致。
* 地址解析：按生态与名称解析文档或仓库地址。联网并更新注册表缓存，失败返回分类错误、提示与后续动作。

## 探查

* 探查文档站：只返回站点结构，不存储。作用域以字典传入，支持采样条数。
* 探查仓库：只返回目录结构，不解析。支持子目录、文件数上限与采样条数。

## 源码洞察

* 接口视角：频次榜、同现接口、参数形状。部分视图要求给出接口名。
* 序列与结构视角：模式列表、模式证据、特征树、分组、健康、标签、片段。证据视图要求非空序列，去重为开启、关闭与默认三态。
* 符号视角：详情、文件内符号、子符号、签名。部分视图要求给出符号名。
* 调用视角：按被调、主调、文件三向查看，要求给出调用名，支持歧义开关与调用过滤。
* 导入视角：导入者与文件导入两向查看，要求给出目标或文件。
* 仓库依赖：查询某版本清单声明的依赖，要求给出库名与版本。
* 健康度量：复用度与多样性信号，接受可选的库、版本与生态过滤。

## 治理

* 审核：列出待定项或对单实体批准、标冲突、重开。非法流转返回冲突，缺参返回参数错误。
* 任务查看：无编号返回最近任务列表，给定编号返回任务详情，未知编号返回未找到。本工具只读，不提交任务。
